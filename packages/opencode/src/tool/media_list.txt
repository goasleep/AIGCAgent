List or search the project media library. Every generated, processed, or uploaded image/video is stored here with its asset id (med_...), project-relative path, dimensions or duration, source, model, and prompt. Filter with query (case-insensitive substring over prompt, model, and original filename), kind, and source; results are newest first and paginated — pass next_cursor from the previous page to continue. Use the returned asset id as an input to media_process, media_generate_image (image/mask), or media_generate_video (first_frame/last_frame).
