Process media with ffmpeg using a whitelisted template (no free-form command line). Templates: transcode, trim (lossless fast cut), trim_exact (frame-accurate re-encode), concat, extract_frames (output must contain a printf pattern like %03d), watermark, make_gif, resize_image, thumbnail. All inputs/output are project-relative paths; the output is moved into the project media library (.opencode/media/) and returned with its asset id and a serve URL. Set params.timeout_ms to override the default timeout (image 60s, video 10min, hard cap 30min).
