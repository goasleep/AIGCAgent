Generate a video with the configured video model (default seedance-2-0 via Volcengine Ark; also supports Alibaba Wan e.g. wan3.0-video via DashScope, and MiniMax-H3). This is a paid API call — the user is asked for confirmation before it runs. The task runs in the background (up to ~15min polling) with visible progress; the result is saved into the project media library and attached to the conversation as a video playable inline. Retries are NOT idempotent: re-calling with the same prompt generates and charges again.

Optional first_frame / last_frame take project-relative image paths (png/jpg) and guide the generated clip's opening/closing frame — use them to keep a regenerated segment continuous with surrounding footage. Typical segment-regeneration flow: media_process trim_exact to split head/tail, media_process extract_frames with timestamps at the cut boundaries, then media_generate_video with those frames, then media_process concat. Frame support by provider: seedance (Ark) accepts both frames; MiniMax accepts first_frame only; Wan (DashScope) accepts neither and errors when frames are passed.
